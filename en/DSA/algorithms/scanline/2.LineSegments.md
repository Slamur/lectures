# Segments on the line

In previous section we discussed some problems with applying "increment on range" operations on arrays.

Most known applications of this technique are related to segments on the line.

We will consider segments on the integer line $[0, M)$ only.

## Problems

### Length of Segments Union

#### Problem

You are given $N$ segments $[L_i, R_i]$ on the line.

Find the total length of their union in $O(N + M)$ time.

#### Solution

- Let's denote an array $C$ of size $M$ initialized with zeros.
  - $C_i$ will store how many segments cover the point $i$ on the line.
  - Then the total length of union of segments is the number of positions $i$ where $C_i > 0$.
  
- Each segment $[L_i, R_i]$ is essentially a range increment operation on the array $C$.
  - use already known "difference array" technique to apply all range increments in $O(N)$ time.
  - Then restore the array $C$ by calculating prefix sums in $O(M)$ time.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> covered(m + 1, 0); // Difference array of size m + 1
    // Apply all segments as range increment operations to the difference array (1-indexation)
    for (const auto& [left, right] : segments) {
        covered[left] += 1;
        covered[right + 1] -= 1;
    }
    
    // Restore the array C by calculating prefix sums of the difference array
    for (int i = 1; i <= m; ++i) {
        covered[i] += covered[i - 1];
    }
    
    // Count the number of positions covered by at least one segment
    ans_t ans = 0;
    for (int i = 1; i <= m; ++i) {
        if (covered[i] > 0) {
            ans += 1;
        }
    }
    
    return ans;
}
```

### Amount of intersections

#### Problem

You are given $N$ segments $[L_i, R_i]$ on the line.

For each segment count how many other segments intersect with it.

#### Solution

- Let's denote $C_i$ as amount of segments **intersecting** with the $i$-th segment.
  - Two segments $[L_i, R_i]$ and $[L_j, R_j]$ intersect if and only if $\max(L_i, L_j) \le \min(R_i, R_j)$.
  - This inequality is a bit difficult to work with directly, so let's transform the problem a bit.
- Let's denote $S_i$ as amount of segments **not intersecting** with the $i$-th segment.
  - Then $C_i = N - 1 - S_i$.
  - Two segments $[L_i, R_i]$ and $[L_j, R_j]$ do not intersect in two **independent** cases:
    - $R_i < L_j$,
    - $R_j < L_i$.
- So $S_i$ can be computed as the sum of two independent counts:
  - amount of segments $j$ where $R_j < L_i$, denote this as $S^L_i$,
  - amount of segments $j$ where $R_i < L_j$, denote this as $S^R_i$.
- Let's compute $S^L_i$ for all segments:
  - $S^L_i = \sum_{k = 0}^{L_i - 1} E_k$, where $E_k$ is amount of segments ending at position $k$.
    - $S^L_i$ is essentially a **prefix sum** query on the array $E$ at the position $L_i - 1$.
- Segment $i$ ends at the position $R_i$, so we can build the array $E$ as `e[R_i] += 1` for each segment $i$.
- Similarly, we can compute $S^R_i$ for all segments, but using **suffix sums**.
  - Alternatively, we can reverse the line and segments and use the same approach as for $S^L_i$.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> starts(m + 1, 0); // starts[i]
    std::vector<int> ends(m + 1, 0); // ends[i]

    // Build the starts and ends array
    for (const auto& [left, right] : segments) {
        starts[left] += 1;
        ends[right] += 1;
    }

    // Precompute prefix sums of ends array
    std::vector<int> s_right(starts.begin(), starts.end());
    std::vector<int> s_left(ends.begin(), ends.end()));
    
    for (int i = 1; i <= m; ++i) {
        s_left[i] += s_left[i - 1];
    }
    
    for (int i = m - 1; i >= 0; --i) {
        s_right[i] += s_right[i + 1];
    }

    std::vector<int> ans(n, 0);
    for (int i = 0; i < n; ++i) {
        const auto& [left, right] = segments[i];
        int to_the_left = (left > 0) ? s_left[left - 1] : 0;
        int to_the_right = (right < m) ? s_right[right + 1] : 0;
        int not_intersecting = to_the_left + to_the_right;
        ans[i] = (n - 1) - not_intersecting;
    }

    return ans;
}
```
