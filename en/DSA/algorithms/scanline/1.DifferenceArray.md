# Difference array

## Definition

**Difference array** $D$ of array $A$ is an array of the same size, where:

- $D_1 = A_1$
- $D_i = A_i - A_{i - 1}$ for $i > 1$.

$D_1$ can be seen as $A_1 - A_0$, where $A_0 = 0$.

### Connection with prefix sums

**Prefix sums** and **difference array** are **inverse operations** to each other:

- **Prefix sums** of array $D$ gives us back the original array $A$:
  - $A_i = \sum_{j = 1}^{i} D_j$.
- Compare it with continuous case: **derivative** (difference array) and **integral** (prefix sums).

## Applications

### (Offline) Range increment in O(1)

#### Problem

You have an array of size $N$ initialized with zeros. You need to perform $M$ operations of the following type:

- Increment all elements in the range $[L, R]$ by value $X$.
- **After all operations**, output the resulting array.

#### Solution

- We know that each increment operations changes all elements of the array $A$ in the range $[L, R]$ by $X$.
  - But what about the difference array $D$?
  
- The main observation is that each operation affects only two positions in the difference array $D$:
  - $D_L = A_L - A_{L - 1}$ is increased by $X$ ($A_L$ changed and $A_{L - 1}$ didn't). 
  - $D_{R + 1} = A_{R + 1} - A_R$ is decreased by $X$ ($A_R$ changed and $A_{R + 1}$ didn't).
     
- Don't forget to check whether $R + 1 \le N$ to avoid out-of-bounds access.
  - Often it's easier to allocate $D$ of size $N + 1$ to avoid checking the boundary condition.
  
- After performing all operations, we can restore the resulting array $A$ by calculating prefix sums of $D$.
  - Notice that this approach is possible only because we don't need intermediate states of $A$.

#### Implementation

```cpp
auto get_ans = [&]() {
    vector<int> diff(n + 1, 0); // Difference array of size n + 1

    // Apply all operations to the difference array (0-indexation)
    for (const auto& [left, right, delta] : queries) {
        diff[left] += delta;
        diff[right + 1] -= delta;
    }

    // Restore the resulting array A by calculating prefix sums of D
    vector<int> ans(diff.begin(), diff.end());
    for (int i = 1; i < n; ++i) {
        ans[i] += ans[i - 1];
    }

    return ans;
}
```
