# Difference array

## Definition

**Difference array** $D$ of array $A$ is an array of the same size, where:

- $D_1 = A_1$
- $D_i = A_i - A_{i - 1}$ for $i > 1$.

$D_1$ can be seen as $A_1 - A_0$, where $A_0 = 0$.

### Connection with prefix sums

**Prefix sums** and **difference array** are **inverse operations** to each other:

- **Prefix sums** of array $D$ gives us back the original array $A$:
  - $A_i = \sum_{j = 1}^{i} D_j$.
- Compare it with continuous case: **derivative** (difference array) and **integral** (prefix sums).

## Applications

### (Offline) Range increment in O(1)

#### Problem

You have an array of size $N$ initialized with zeros. You need to perform $M$ operations of the following type:

- Increment all elements in the range $[L, R]$ by value $X$.
- **After all operations**, output the resulting array.

#### Solution

- We know that each increment operations changes all elements of the array $A$ in the range $[L, R]$ by $X$.
  - But what about the difference array $D$?
  
- The main observation is that each operation affects only two positions in the difference array $D$:
  - $D_L = A_L - A_{L - 1}$ is increased by $X$ ($A_L$ changed and $A_{L - 1}$ didn't). 
  - $D_{R + 1} = A_{R + 1} - A_R$ is decreased by $X$ ($A_R$ changed and $A_{R + 1}$ didn't).
     
- Don't forget to check whether $R + 1 \le N$ to avoid out-of-bounds access.
  - Often it's easier to allocate $D$ of size $N + 1$ to avoid checking the boundary condition.
  
- After performing all operations, we can restore the resulting array $A$ by calculating prefix sums of $D$.
  - Notice that this approach is possible only because we don't need intermediate states of $A$.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> diff(n + 1, 0); // Difference array of size n + 1

    // Apply all operations to the difference array (0-indexation)
    for (const auto& [left, right, delta] : queries) {
        diff[left] += delta;
        diff[right + 1] -= delta;
    }

    // Restore the resulting array A by calculating prefix sums of D
    std::vector<int> ans(diff.begin(), diff.end());
    for (int i = 1; i < n; ++i) {
        ans[i] += ans[i - 1];
    }

    return ans;
}
```

### Maximize sum of range sum queries

#### Problem

You have an array $A$ of size $N$ and $Q$ queries. 

Each query contains two integers $L$ and $R$ - you need to find the sum of elements in the range $[L, R]$.

Reorder the elements of the array $A$ to maximize the total sum of answers to all queries.

#### Solution

- Let's denote the total sum of answers to all queries as $S$.
  - $S = \sum_{j = 1}^{Q} \sum_{i = L_j}^{R_j} A_i$.

- Let's denote the predicate that position $i$ is included in query $j$ as $I_{i, j}$:
  - $I_{i, j} = 1$, if $L_j \le i \le R_j$;
  - $I_{i, j} = 0$, otherwise.

- Then we can rewrite $S$ as:
  - $S = \sum_{j = 1}^{Q} \sum_{i = 1}^{N} A_i \cdot I_{i, j}$.
  - It can be rewritten as $S = \sum_{i = 1}^{N} A_i \cdot \left( \sum_{j = 1}^{Q} I_{i, j} \right)$.

- It's easy to see that $\left( \sum_{j = 1}^{Q} I_{i, j} \right)$ is the number of queries that include position $i$.
  - Let's denote this value as **frequency** $F_i$ of position $i$.
  - So $S = \sum_{i = 1}^{N} A_i \cdot F_i$.
  
- $F_i$ can be calculated using the difference array approach:
  - Each query $[L, R]$ increases the frequency of all positions in the range $[L, R]$ by $1$.

- To maximize $S$, we need to assign the largest elements of $A$ to the largest frequencies in $F$.
  - It can be done by sorting both arrays $A$ and $F$ in non-decreasing order and calculating the sum of products.
    - $S = \sum_{i = 1}^{N} A^S_i \cdot F^S_i$, where $A^S$ and $F^S$ are sorted arrays.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> freq(n + 1, 0); // Frequency array

    // Calculate frequencies using difference array approach
    for (const auto& [left, right] : queries) {
        freq[left] += 1;
        freq[right + 1] -= 1;
    }

    // Restore frequencies by calculating prefix sums
    for (int i = 1; i < n; ++i) {
        freq[i] += freq[i - 1];
    }
    
    freq.pop_back(); // Remove the extra element

    std::sort(a.begin(), a.end());
    std::sort(freq.begin(), freq.end());

    ans_t ans  = 0;
    for (int i = 0; i < n; ++i) {
        ans += (ans_t)a[i] * freq[i];
    }

    return ans;
}
```
