# Online Queries at Critical Points

Until now, we have discussed problems where all queries were known in advance.

But what to do if the queries are unknown in advance?

Or if "get" queries are mixed with "update" queries?

In such cases, the technique of **coordinate compression** can help us.

## Coordinate Compression

We will divide the process of processing stability intervals into two parts:

- finding and **numbering** critical points in increasing order - this is **coordinate compression**;
- then we use these compressed coordinates to answer the existing queries.

The main convenience of this approach lies in the ability to use various data structures that implement certain **range queries** on the array:

- difference array;
- segment tree / Fenwick tree;
- square root decomposition;
- etc.

### Array of Critical Points

First, we need to collect all critical points in sorted order.

Most often, we aim to keep only unique values to minimize the size of the resulting array.

#### Search Tree

```cpp
auto get_critical_points = [&]() {
    search_tree_set<int> critical_points_set;
    
    // Collect critical points from segments
    for (const auto& [left, right, _] : segments) {
        critical_points_set.insert(left);
        critical_points_set.insert(right + 1);
    }
    
    // Collect critical points from queries
    for (const auto& [coord, _] : queries) {
        critical_points_set.insert(coord);
    }
    
    // Transfer to vector
    std::vector<int> critical_points(critical_points_set.begin(), critical_points_set.end());
    
    return critical_points;
}
```

#### Sorting and Removing Duplicates

```cpp
auto get_critical_points = [&]() {
    std::vector<int> critical_points;

    // Collect critical points from segments 
    for (const auto& [left, right, _] : segments) {
        critical_points.push_back(left);
        critical_points.push_back(right + 1);
    }

    // Collect critical points from queries

    for (const auto& [coord, _] : queries) {
        critical_points.push_back(coord);
    }

    // Sort and remove duplicates
    std::sort(critical_points.begin(), critical_points.end());
    
    // magic C++
    
    // removes all elements in the specified range
    critical_points.erase(
        // moves all unique elements to the front, returns "new end"
        // expects a sorted range 
        std::unique(critical_points.begin(), critical_points.end()),  
        critical_points.end()
    );
    
    /*
    If you are using a language without built-in support for removing duplicates,
    you can do it manually:

    std::vector<int> unique_points;
    for (size_t i = 0; i < critical_points.size(); ++i) {
        if (i == 0 || critical_points[i] != critical_points[i - 1]) {
            unique_points.push_back(critical_points[i]);
        }
    }
    
    */    
    
    return critical_points;
}
```

### Mapping Compressed Coordinates

Now we need to learn how to map original coordinates to their compressed counterparts.

#### Hash Table

This approach is relevant only if the coordinates of the queries are also known in advance so that they can be compressed.

```cpp
auto build_compression_map = [&](const std::vector<int>& critical_points) {
    hash_table_map<int, int> compression_map;
    
    for (size_t i = 0; i < critical_points.size(); ++i) {
        compression_map[critical_points[i]] = i;
    }
    
    return compression_map;
}

auto compress_coordinate = [&](int coord, const hash_table_map<int, int>& compression_map) {
    return compression_map.get(coord); // return the compressed coordinate
}
```

#### Binary Search

Although this technique theoretically has worse asymptotic complexity $O(\log N)$ per query, in practice, it often turns out to be faster due to smaller constants and the absence of overhead from hash tables.

This approach also works even if only the coordinates of the segments are known in advance, but not the queries.

```cpp
auto compress_coordinate = [&](int coord, const std::vector<int>& critical_points) {
    // Find the position of coord in the array critical_points using binary search
    auto it = std::lower_bound(critical_points.begin(), critical_points.end(), coord);
    
    // Return the index of the compressed coordinate
    return std::distance(critical_points.begin(), it);
}
```

## Application in Problems

All problems below require processing queries in **online** mode.

### Number of Covering Segments

#### Problem

Given $N$ segments $[L_i, R_i]$ on the number line and $Q$ queries $x_j$.

For the $j$-th query, find the number of segments that cover point $x_j$.

#### Solution

- Compress the coordinates of the segment boundaries.
- Use a difference array for "range increment" operations.
- To answer each query, find the interval that contains the point.
  - The interval search is performed using binary search.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> critical_points = get_critical_points();
    
    // Build the difference array
    std::vector<int> cover_count(critical_points.size() + 1, 0);
    for (const auto& [left, right] : segments) {
        int compressed_left = compress_coordinate(left, critical_points);
        int compressed_right = compress_coordinate(right, critical_points);
        
        cover_count[compressed_left] += 1;
        cover_count[compressed_right + 1] -= 1;
    }
    
    // Compute the number of coverings
    for (size_t i = 1; i < cover_count.size(); ++i) {
        cover_count[i] += cover_count[i - 1];
    }
    
    // Answer the queries
    std::vector<int> answers;
    for (const auto& coord : queries) {
        int compressed_coord = compress_coordinate(coord, critical_points);
        answers.push_back(cover_count[compressed_coord]);
    }
    
    return answers;
}
```

### Sum of Colors of Points in Range

#### Problem

Given $N$ segments $[L_i, R_i]$ on the number line, each of which has color $C_i$.

The color of point $x$ is equal to the sum of the colors of the segments covering it: $color(x) = \sum_{i: L_i \le x \le R_i} C_i$.

Also given $Q$ queries $[S_j, E_j]$ - find the sum of colors of points in the range: $\sum_{x = S_j}^{E_j} color(x)$.

#### Solution

- Compress the coordinates of the segment boundaries.
- Use a difference array for "range increment" operations considering the colors of the segments.
- To answer each query, find the compressed coordinates of the range boundaries and compute the sum using prefix sums.
- Each query is split into two parts:
  - sum from the start to $E_j$;
  - sum from the start to $S_j - 1$;
  - the difference of the two sums gives the answer to the query.
- Note that the coordinates of the query $x$ ($S_j - 1$ and $E_j$) may lie in the middle of stability intervals.
  - find the nearest smaller critical point $K_i$ for the query point.
  - for it, extract the precomputed prefix sum.
  - for the segment $(K_i, x]$, the color of the points is constant, so the sum equals $color(K_i) \cdot (x - K_i)$.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> critical_points = get_critical_points();
    
    // Build the difference array considering colors
    std::vector<ans_t> color_sum(critical_points.size() + 1, 0);
    for (const auto& [left, right, color] : segments) {
        int compressed_left = compress_coordinate(left, critical_points);
        int compressed_right = compress_coordinate(right, critical_points);
        
        color_sum[compressed_left] += color;
        color_sum[compressed_right + 1] -= color;
    }
    
    // Compute the color of points
    for (size_t i = 1; i < color_sum.size(); ++i) {
        color_sum[i] += color_sum[i - 1];
    }
    
    // Compute prefix sums of colors
    std::vector<ans_t> prefix_sum(color_sum.size(), 0);
    for (size_t i = 0; i + 1 < color_sum.size(); ++i) {
        ans_t segment_length = critical_points[i + 1] - critical_points[i];
        prefix_sum[i + 1] = prefix_sum[i] + color_sum[i] * segment_length;
    }
    
    auto calculate_prefix_sum = [&](int coord) {
        int compressed_coord = compress_coordinate(coord, critical_points);
        ans_t result = prefix_sum[compressed_coord];
        
        // Account for the part from the critical point to coord
        if (critical_points[compressed_coord] < coord) {
            result += color_sum[compressed_coord] * (coord - critical_points[compressed_coord]);
        }
        
        return result;
    };
    
    // Answer the queries
    std::vector<ans_t> answers;
    for (const auto& [start, end] : queries) {
        int compressed_start = compress_coordinate(start, critical_points);
        int compressed_end = compress_coordinate(end, critical_points);
        
        ans_t answer = calculate_prefix_sum(end) - calculate_prefix_sum(start - 1);
        
        answers.push_back(answer);
    }
    
    return answers;
}
```

### Product of Colors of Points in Range

#### Problem

Given $N$ segments $[L_i, R_i]$ on the number line, each of which has color $C_i$.

The color of point $x$ is equal to the sum of the colors of the segments covering it: $color(x) = \sum_{i: L_i \le x \le R_i} C_i$.

Also given $Q$ queries $[S_j, E_j]$ - find the **product** of the colors of points in the range: $\sum_{x = S_j}^{E_j} color(x)$.

The answers to the queries must be output modulo a given $M$.

#### Solution

- Compress the coordinates of the segment boundaries.
- Use a difference array for "range increment" operations considering the colors of the segments.
- The product on each interval can be calculated using fast exponentiation.
- Since $M$ can be any value, division modulo is not guaranteed.
  - Accordingly, the approach with prefix products cannot be applied.
- Split the query into **three** parts:
  - Let $S_j < K_S < K_E < E_j$, where $K_S$ and $K_E$ are the nearest critical points to $S_j$ and $E_j$, respectively.
  - Compute the product on three segments:
    - from $S_j$ to $K_S$ - $color(S_j)$ raised to the power ${(K_S - S_j + 1)}$;
    - from $K_S$ to $K_E$ - product of intervals in the range.
    - from $K_E$ to $E_j$ - $color(E_j)$ raised to the power ${(E_j - K_E)}$.
- The product of intervals can be computed using various data structures, for example:
  - segment tree;
  - square root decomposition.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> critical_points = get_critical_points();
    
    // Build the difference array considering colors
    std::vector<ans_t> color_sum(critical_points.size() + 1, 0);
    for (const auto& [left, right, color] : segments) {
        int compressed_left = compress_coordinate(left, critical_points);
        int compressed_right = compress_coordinate(right, critical_points);
        
        color_sum[compressed_left] += color;
        color_sum[compressed_right + 1] -= color;
    }
    
    // Compute the color of points
    for (size_t i = 1; i < color_sum.size(); ++i) {
        color_sum[i] += color_sum[i - 1];
    }
    
    // Compute products on each interval
    std::vector<ans_t> products(critical_points.size(), 1);
    for (size_t i = 0; i + 1 < color_sum.size(); ++i) {
        ans_t segment_length = critical_points[i + 1] - critical_points[i];
        products[i] = fast_pow(color_sum[i], segment_length, M);
    }
    
    // Build a data structure for computing products in the range
    RangeProduct<ans_t> range_product_ds(products);
    
    // Answer the queries
    std::vector<ans_t> answers;
    for (const auto& [start, end] : queries) {
        int compressed_start = compress_coordinate(start, critical_points) + 1; // nearest greater
        int compressed_end = compress_coordinate(end, critical_points);
        
        ans_t answer = 1;
        // Left part from start to the nearest critical point
        if (critical_points[compressed_start] > start) {
            ans_t left_color = color_sum[compressed_start];
            ans_t left_length = critical_points[compressed_start] - start;
            answer = (answer * fast_pow(left_color, left_length, M)) % M;
        }
        
        // Middle part from the nearest critical point to the nearest critical point
        if (compressed_start < compressed_end) {
            ans_t middle_product = range_product_ds.query(compressed_start, compressed_end - 1);
            answer = (answer * middle_product) % M;
        }
        
        // Right part from the nearest critical point to end
        if (critical_points[compressed_end] <= end) {
            ans_t right_color = color_sum[compressed_end];
            ans_t right_length = end - critical_points[compressed_end] + 1;
            answer = (answer * fast_pow(right_color, right_length, M)) % M;
        }
        
        answers.push_back(answer);
    }
    
    return answers;
}
```
