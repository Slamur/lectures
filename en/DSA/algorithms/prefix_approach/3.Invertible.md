# Invertible operations

Some binary operations are **invertible**:

- let's denote binary operation as $\oplus$ and it's inversion as $\ominus$;
- then for any elements $a$, $b$ and $c$:
  - if $a \oplus b = c$, then $c \ominus b = a$ and $c \ominus a = b$.

The most common examples of invertible operations are:

- addition / subtraction;
- multiplication / division (except division by zero).
- XOR / XOR (XOR is its own inverse).

## Range queries with invertible operations

If the binary operation is invertible, then it's possible to answer range queries using only prefix results.

Lets $F(L, R) = A_{L + 1} \oplus \ldots \oplus A_R$.

Then we can express $F(L, R) = Pref_R \ominus Pref_L$, where $Pref_i = F(0, i)$.

### Range sum queries

#### Problem

You have an array of $n$ integers and $q$ queries.

Each query contains two integers $L$ and $R$ ($1 \le L \le R \le n$) - you need to find the sum of elements from index $L$ to index $R$.

#### Solution

- Notice that sum is an invertible operation (inversion is subtraction).
- Thus, you can precalculate prefix sums and answer each query as $Pref_R - Pref_L$.
- Total time complexity is $O(N + Q)$.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<long long> prefix_sums(n + 1, 0);
    for (size_t i = 0; i < n; i++) {
        prefix_sums[i + 1] = prefix_sums[i] + a[i];
    }
        
    std::vector<long long> answers;
    for (auto& [left, right] : queries) {
        long long ans = prefix_sums[right] - prefix_sums[left - 1];
        answers.push_back(ans);
    }
    
    return answers;
}
```

### Range with the maximal xor

#### Problem

You have an array of $n$ integers.

You need to find the **maximal** bitwise XOR ($\oplus$, `^`) of a subarray $A_L, A_{L + 1}, \ldots, A_R$.

#### Solution

- $S(L, R) = Pref_R \oplus Pref_{L - 1}$.
- Let's fix $R$ and try to find the best $L$ for it.
  - for the fixed $R$ the value $Pref_R$ is constant.
  - so to maximize $S(L, R)$ we need to minimize $Pref_{L - 1}$.
- Thus, we can iterate over $R$ from $1$ to $n$, keeping track of the minimal prefix XOR for $L - 1$ seen so far.
  - It can be stored in an array or even a single variable.
- Total time complexity is $O(N)$.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<long long> prefix_xors(n + 1, 0);
    for (size_t i = 0; i < n; i++) {
        prefix_xors[i + 1] = prefix_xors[i] ^ a[i];
```

### Predicate amount range queries

#### Problem

You have an array of $n$ integers and $q$ queries.

Also, you have a predicate function $P(x)$ that returns true or false for any integer $x$.

Each query contains two integers $L$ and $R$ ($1 \le L \le R \le n$) - you need to find how many elements in the subarray from index $L$ to index $R$ satisfy the predicate.

#### Solution

- Let's create an auxiliary array $B$ of size $n$, where $B_i = 1$ if $P(A_i)$ is true, and $0$ otherwise.
- Then the answer for the query is the sum of elements from index $L$ to index $R$ in the array $B$.
- We can use the range sum queries approach to answer those queries.
- Total time complexity is $O(N + Q)$.

#### Implementation

```cpp
auto get_ans = [&]() {
    std::vector<int> b(n, 0);
    for (size_t i = 0; i < n; i++) {
        b[i] = P(a[i]) ? 1 : 0;
    }

    std::vector<long long> prefix_sums(n + 1, 0);
    for (size_t i = 0; i < n; i++) {
        prefix_sums[i + 1] = prefix_sums[i] + b[i];
    }

    std::vector<long long> answers;
    for (auto& [left, right] : queries) {
        long long ans = prefix_sums[right] - prefix_sums[left - 1];
        answers.push_back(ans);
    }

    return answers;
}
```
