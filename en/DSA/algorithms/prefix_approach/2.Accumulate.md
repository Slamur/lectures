# Accumulation Operation

In many problems, it is more efficient to process prefixes/suffixes from empty to the entire array:

- $Pref_i = Pref_{i - 1} \oplus A_i$, where $\oplus$ is the operation of combining the previous result and the new element.
- $Suff_i = A_i \oplus Suff_{i + 1}$.

For empty prefixes/suffixes, the result is usually known (the neutral element of the operation $\oplus$).

In some cases, it is possible to replace the array of accumulated results with a single variable that stores the current result.

## Requirements for the Accumulation Operation

In general, the accumulation operation must be **associative**, meaning that for any $a$, $b$, $c$, the following must hold:

$ (a \oplus b) \oplus c = a \oplus (b \oplus c) $.

It is also desirable for the operation to have a **neutral element** $e$, such that for any $a$:

$ a \oplus e = e \oplus a = a $.

In fact, in this case, we define a **monoid** - an operation on a set $M$ with an associative binary operation $\oplus$ and a neutral element $e \in M$.

## Operations with Fixed Result Size

The most basic examples of accumulation operations are those whose results occupy $O(1)$ memory (the neutral elements are indicated in parentheses):

- minimum (infinity) / maximum (-infinity)
- sum / count (zero)
- greatest common divisor (zero) / least common multiple (one)
- boolean functions: AND (true) / OR (false) / XOR (false)
- etc.

### Duff and Meat

#### Problem

Duff plans to eat meat for $n$ days.

For each day $i$, you know:

- the amount of meat $a_i$ that Duff wants to eat;
- the price per kilogram of meat $p_i$ on that day.

Duff can buy any amount of meat on any day and store it for future days (there are no storage limitations).

Find the minimum total amount of money that Duff must spend to eat the required amount of meat each day.

#### Solution

- To eat meat on day $i$, Duff can buy it on any day $j \le i$;
- To minimize total expenses, Duff should always buy meat on the day with the lowest price at that moment;
- Thus, we need to accumulate the minimum prices for the prefixes of the array $p$:
  - $mp_i = \min(mp_{i - 1}, p_i)$;
- Then the answer will be $\sum_{i = 1}^{n} a_i \cdot mp_i$.

#### Implementation

```cpp
auto get_ans = [&]() {
  int ans = 0;
  
  int inf = 1 + *max_element(p.begin(), p.end());
  
  int min_price = inf;
  for (size_t i = 0; i < n; ++i) {
    min_price = std::min(min_price, p[i]);
    ans += a[i] * min_price;
  }
  
  return ans;
}
```

## Union Operations with Variable Result Size

For such operations, the size of $Pref_i$ usually depends linearly on $i$.

Thus, storing all accumulated results requires $O(N^2)$ memory, which is generally unacceptable.

However, in many cases, it is possible to optimize memory usage to $O(N)$ by storing the result only for the last step and **reusing** it for the next.

Note that in this case, the "answer" for the prefix/suffix does not always coincide with the data structure itself; most often, it is some function of the accumulated data in the structure.

The overall time complexity in this case is $O(N \cdot (Ins + Calc))$, where

- $Ins$ is the time complexity of inserting one element into the result structure;
- $Calc$ is the time complexity of calculating the answer from the result structure.

The neutral element is most often an empty structure.

### Sereja and Suffixes

#### Problem

You have an array $A$ of size $n$ and $q$ queries.

Each query contains an integer $k$ ($1 \le k \le n$) - you need to find how many distinct integers are in the suffix $A_k, A_{k + 1}, \ldots, A_n$.

#### Solution

- It is easy to notice that the answer for the suffix $k \dots n$ is equal to the size of the _set_ of values of this suffix.
  - Let's denote the set for the suffix $k \dots n$ as $S_k$.

- The operation $\oplus$ in this case is the union of sets $\cup$.
  - The neutral element is the empty set $\varnothing$.

- Note that you can precompute the answers for all suffixes before answering the queries.
  - Compute the answers in order from $n$ to $1$ - updating the same set at each iteration.

Formally:

- $S_{n + 1} = \varnothing$;
- $S_{k} = S_{k + 1} \cup (A_k)$.

#### Implementation

```cpp
auto get_ans = [&]() {
  std::vector<size_t> suffix_uniques(n + 1, 0);

  std::unordered_set<int> suffix_set;
  for (int i = n - 1; i >= 0; --i) {
    suffix_set.insert(a[i]);
    suffix_uniques[i] = suffix_set.size();
  }
  
  std::vector<size_t> answers(q);
  for (int j = 0; j < q; ++j) {
    size_t k = queries[j] - 1;
    answers[j] = suffix_uniques[k];
  }
  
  return answers;
}
```
