# Languages

## C++

In C++ Standard Library there are functions (in `<numeric>` header) accumulating specific binary operations over ranges of elements:

- `std::accumulate` - accumulates over a range and returns the final result.
  - parameters:
    - "input" iterators - the range to accumulate over;
    - initial value for the accumulation;
    - (optional) binary operation for accumulation (by default `+`).
- `std::partial_sum` - accumulates over a range and stores all intermediate results.
  - parameters:
    - "input" iterators - the range to accumulate over;
    - "output" iterator - where results will be stored.
    - (optional) binary operation for accumulation (by default `+`).

## Java

In Java Standard Library there are functions accumulating specific binary operations over ranges of elements:

- `Stream.reduce` - accumulates over a stream and returns the final result.
  - parameters:
    - identity value for the accumulation;
    - binary operator for accumulation.
- `Arrays.parallelPrefix` - accumulates over an array and stores all intermediate results.
  - parameters:
    - array to accumulate over;
    - (optional) from index (inclusive);
    - (optional) to index (exclusive);
    - binary operator for accumulation.

## Python

In Python Standard Library there is a function (in `itertools` module) accumulating specific binary operations over ranges of elements:

- `itertools.accumulate` - accumulates over an iterable and returns an iterator of intermediate results.
  - parameters:
    - iterable to accumulate over;
    - (optional) binary function for accumulation (by default `+`).
