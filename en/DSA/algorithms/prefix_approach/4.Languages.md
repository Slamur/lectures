# Programming Languages

Almost all modern programming languages have built-in functions or standard library functions that implement the prefix approach for accumulating specific binary operations over ranges of elements.

Usually they are divided into two categories:

- Functions that accumulate over a range and return the final result.
- Functions that accumulate over a range and store all intermediate results.

## C++

Both functions are located in the `<numeric>` header of C++ Standard Library.

- [`std::accumulate`](https://en.cppreference.com/w/cpp/algorithm/accumulate) - accumulates over a range and returns the final result.
  - parameters:
    - "input" iterators - the range to accumulate over;
    - initial value for the accumulation;
    - (optional) binary operation for accumulation (by default `+`).
    
- [`std::partial_sum`](https://en.cppreference.com/w/cpp/algorithm/partial_sum) - accumulates over a range and stores all intermediate results.
  - parameters:
    - "input" iterators - the range to accumulate over;
    - "output" iterator - where results will be stored.
    - (optional) binary operation for accumulation (by default `+`).

## Java

- [`Stream.reduce`](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/stream/Stream.html#reduce(T,java.util.function.BinaryOperator)) (instance method) - accumulates over a stream and returns the final result.
  - parameters:
    - identity value for the accumulation;
    - binary operator for accumulation.
    
- [`Arrays.parallelPrefix`](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Arrays.html#parallelPrefix(java.lang.Object[],int,int,java.util.function.BinaryOperator)) (static method) - accumulates over an array and stores all intermediate results.
  - parameters:
    - array to accumulate over;
    - (optional) from index (inclusive);
    - (optional) to index (exclusive);
    - binary operator for accumulation.

## Python

- [`functools.reduce`](https://docs.python.org/3/library/functools.html#functools.reduce) - accumulates over an iterable and returns the final result.
  - parameters:
    - binary function for accumulation;
    - iterable to accumulate over;
    - (optional) initial value for the accumulation.

- [`itertools.accumulate`](https://docs.python.org/3/library/itertools.html#itertools.accumulate) - accumulates over an iterable and returns an iterator of intermediate results.
  - parameters:
    - iterable to accumulate over;
    - (optional) binary function for accumulation (by default `+`).
