# Multidimensional Prefix Approach

When working with multidimensional arrays, the prefix approach can be extended to handle submatrices.

For the simplicity, let's consider a 2D array of size $R \times C$.

**2D Prefix** $(i, j)$ of the 2D array is the submatrix that contains all elements $A_{x, y}$ such that $x \in (0, i]$ and $y \in (0, j]$.

## Calculating 2D Prefixes

Lets we have binary operation $\oplus$ with an identity element $e$.

There are two main approaches to calculate 2D prefixes depending on whether the operation is invertible or not.

### General approach

This approach works for any binary operation.

- Use temporary 2D array $RP$ of size $(R + 1) \times (C + 1)$, where for the fixed $i$:
  - $RP_{i, 0} = e$ for all $i$;
  - $RP_{i, j} = RP_{i, j - 1} \oplus A_{i, j}$ for all $j$ from $1$ to $C$.
- Then calculate final 2D prefix array $Pref$ of size $(R + 1) \times (C + 1)$:
  - $Pref_{0, j} = e$ for all $j$;
  - $Pref_{i, j} = Pref_{i - 1, j} \oplus RP_{i, j}$ for all $i$ from $1$ to $R$.
- It's possible to use similar approach by first calculating prefixes by columns and then by rows.

#### Implementation

```cpp
auto get_2d_prefix_min = [&](const std::vector<std::vector<int>>& a) {
    size_t rows_cnt = a.size();
    size_t cols_cnt = a[0].size();
    
    int identity = INT_MAX; // Identity element for min operation

    std::vector<std::vector<int>> row_prefs(rows_cnt + 1, std::vector<int>(cols_cnt + 1, identity));
    for (size_t i = 0; i < rows_cnt; i++) {
        for (size_t j = 0; j < cols_cnt; j++)
            row_prefs[i + 1][j + 1] = std::min(row_prefs[i + 1][j], a[i][j]);
        }
    }   
    
    std::vector<std::vector<int>> prefs(rows_cnt + 1, std::vector<int>(cols_cnt + 1, identity));
    for (size_t j = 0; j < cols_cnt; j++) {
        for (size_t i = 0; i < rows_cnt; i++)
            prefs[i + 1][j + 1] = std::min(prefs[i][j + 1], row_prefs[i + 1][j + 1]);
        }
    }
}
```

### Invertible operation approach

If the binary operation is invertible, then it's possible to calculate 2D prefixes in a more straightforward way:

$Pref_{i, j} = (Pref_{i - 1, j} \oplus Pref_{i, j - 1} \ominus Pref_{i - 1, j - 1}) \oplus A_{i, j}$:

- Elements in the $i$ -th row to the left from $j$-th are added only once;
- Elements in the $j$ -th column above from $i$-th are added only once;
- Elements in the top-left submatrix $(i - 1, j - 1)$ are added twice, so we need to subtract them once.

#### Implementation

```cpp
auto get_2d_prefix_sum = [&](const std::vector<std::vector<int>>& a) {
    size_t rows_cnt = a.size();
    size_t cols_cnt = a[0].size();

    int identity = 0; // Identity element for sum operation

    std::vector<std::vector<int>> prefs(rows_cnt + 1, std::vector<int>(cols_cnt + 1, identity));
    for (size_t i = 0; i < rows_cnt; i++) {
        for (size_t j = 0; j < cols_cnt; j++) {
            prefs[i + 1][j + 1] = prefs[i][j + 1] + prefs[i + 1][j] - prefs[i][j] + a[i][j];
        }
    } 
}
```

## Range queries (for invertible operations)

If the binary operation is invertible, then it's possible to answer submatrix queries using only 2D prefix results.

Lets $F(R_1, C_1, R_2, C_2)$ be the result of applying the binary operation to all elements in the submatrix defined by top-left corner $(R_1, C_1)$ and bottom-right corner $(R_2, C_2)$.

Then we can express:

$F(R_1, C_1, R_2, C_2) = Pref_{R_2, C_2} \ominus Pref_{R_1 - 1, C_2} \ominus Pref_{R_2, C_1 - 1} \oplus Pref_{R_1 - 1, C_1 - 1}$:

- Elements in the prefix $(R_2, C_2)$ are added once;
- Elements in the prefix $(R_1 - 1, C_2)$ (above the submatrix) are subtracted once;
- Elements in the prefix $(R_2, C_1 - 1)$ (to the left of the submatrix) are subtracted once;
- Elements in the prefix $(R_1 - 1, C_1 - 1)$ (top-left corner) are subtracted twice, so we need to add them once.

#### Implementation

```cpp
auto get_submatrix_sum = [&](const std::vector<std::vector<int>>& pref_sums,
                             size_t r1, size_t c1, size_t r2, size_t c2) {
    return pref_sums[r2][c2]
           - pref_sums[r1 - 1][c2]
           - pref_sums[r2][c1 - 1]
           + pref_sums[r1 - 1][c1 - 1];
}
```

### Maximal sum of the submatrix

#### Problem

You have a 2D array of size $R \times C$.

You need to find the submatrix with the maximal sum of elements.

#### Solution

- Calculate 2D prefix sums.
- In the 1D-case we have fixed right border $R$ and looked for the best left border $L$.
  - this approach can't be extended as is to 2D-case, because we have two borders to fix - right and bottom.
- Instead, we can fix the top and bottom borders $R_1$ and $R_2$ and reduce the problem to 1D-case.
  - For the fixed $C_2$ you need to find the best $C_1$ to maximize the sum of the submatrix $(R_1, C_1)$ to $(R_2, C_2)$.
- Total time complexity is $O(R^2 \cdot C)$.
  - If $C > R$, then it's better to fix left and right borders and iterate over top and bottom borders - total time complexity will be $O(C^2 \cdot R)$.

#### Implementation

```cpp
auto get_max_submatrix_sum = [&](const std::vector<std::vector<int>>& a) {
    size_t rows_cnt = a.size();
    size_t cols_cnt = a[0].size();

    // Calculate 2D prefix sums
    std::vector<std::vector<int>> pref_sums = calculate_2d_prefix_sums(a);

    int max_sum = INT_MIN;
    for (size_t top = 1; top <= rows_cnt; top++) {
        for (size_t bottom = top; bottom <= rows_cnt; bottom++) {
            int min_prefix_sum = 0;
            
            for (size_t col = 1; col <= cols_cnt; col++) {
                // Calculate sum of the column segment from top to bottom
                int right_sum = get_submatrix_sum(pref_sums, top, 1, bottom, col);
                max_sum = std::max(max_sum, right_sum - min_prefix_sum);
                min_prefix_sum = std::min(min_prefix_sum, right_sum);
            }
        }
    }
    
    return max_sum;
}
```

## Generalization to higher dimensions

### Calculation

Usually general approach is easier to implement for higher dimensions - just iterate over all dimensions one by one, calculating prefixes along each dimension.

Invertible operation approach can be generalized as well, but the formula becomes much more complex with each new dimension.

### Range queries (for invertible operations)

The formula can be generalized to higher dimensions as well, using **inclusion-exclusion principle**:

- it requires $2^D$ terms for $D$-dimensional array;
- each term corresponds to one corner of the hyperrectangle defined by the query;
- sign of each term is determined by the parity of the number of dimensions where the corner is at the "lower" side of the query range.

#### Implementation

`bit_count` is an abstract function that counts number of `1` bits in the binary representation of the number.

```cpp
auto get_subhyperrectangle_sum = [&](const std::vector<std::vector<std::vector<int>>>& pref_sums,
                                     const std::vector<size_t>& start,
                                     const std::vector<size_t>& end) {
    int result = 0;
    
    size_t dimensions = start.size();
    size_t corners_cnt = 1 << dimensions; // 2^D corners
    
    for (size_t corner = 0; corner < corners_cnt; corner++) {
        int sign = (bit_count(corner) % 2 == 0) ? 1 : -1;
        
        std::vector<size_t> indices(dimensions);
        for (size_t dim = 0; dim < dimensions; dim++) {
            if (corner & (1 << dim))
                indices[dim] = end[dim];
            else
                indices[dim] = start[dim] - 1;
        }
        
        result += sign * get_pref_value(pref_sums, indices);
    }
    
    return result;
}
```
