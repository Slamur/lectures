# Prefix and suffix

## Definitions

**Prefix** of the sequence (array / string / etc.) is any amount of the first elements (even zero).

**Suffix** - similar to prefix, but the last elements.

### Amount of prefixes and suffixes

For array of size $N$ there are $N + 1$ prefixes and $N + 1$ suffixes (including empty ones).

In the most cases it's convenient to numerate prefixes and suffixes by the amount of elements they contain:

- $Pref_0 = [\ ]$;
- $Pref_1 = [A_1]$;
- $Pref_2 = [A_1, A_2]$;
- $\ldots$
- $Pref_N = [A_1, A_2, \ldots, A_N]$.

From the indexation point of view it's easier to use semi-open intervals: $(0, i]$ for prefixes and $[i, N)$ for suffixes.

# Function accumulation

## General

In some problems it's more efficient to process prefixes / suffixes from the empty ones to the whole array:

- $Pref_i = Combine(Pref_{i - 1}, A_i)$.
- $Suff_i = Combine(A_i, Suff_{i + 1})$.

## Accumulate function on the prefix

You can calculate minimum / maximum (and some other operations) for every prefix of the array with total complexity $O(N)$:

- $PrefMin_0 = Inf$;
- $PrefMin_i = \min{(PrefMin_{i - 1}, A_i)}$.

### Duff and Meat

For each day $i$ find minimum price $mp_i$ in days $1 \dots i$.

You can even replace array $mp_i$ by one variable $mp$.

```cpp
auto get_ans = [&]()
{
  int ans = 0;
  
  int inf = 1 + *max_element(p.begin(), p.end());
  
  int min_price = inf;
  for (size_t i = 0; i < n; ++i)
  {
    min_price = std::min(min_price, p[i]);
    ans += a[i] * min_price;
  }
  
  return ans;
}
```
