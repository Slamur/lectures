# Разностный массив

## Определение

**Разностный массив** $D$ массива $A$ --- это массив такого же размера, где:

- $D_1 = A_1$
- $D_i = A_i - A_{i - 1}$ для $i > 1$.

$D_1$ можно рассматривать как $A_1 - A_0$, где $A_0 = 0$.

### Связь с префиксными суммами

**Префиксные суммы** и **разностный массив** являются **обратными операциями** друг к другу:

- **Префиксные суммы** массива $D$ возвращают нам исходный массив $A$:
  - $A_i = \sum_{j = 1}^{i} D_j$.
- Сравните это с непрерывным случаем: **производная** (разностный массив) и **интеграл** (префиксные суммы).

## Применения

### (Офлайн) Инкремент (прибавление) в диапазоне за O(1)

#### Задача

У вас есть массив размером $N$, инициализированный нулями. Вам нужно выполнить $Q$ операций следующего типа:

- Увеличить все элементы в диапазоне $[L, R]$ на значение $X$.
- **После всех операций** выведите результирующий массив.

#### Решение

- Мы знаем, что каждая операция увеличивает все элементы массива $A$ в диапазоне $[L, R]$ на $X$.
  - Но что насчет разностного массива $D$?
  
- Главное наблюдение заключается в том, что каждая операция влияет только на две позиции в разностном массиве $D$:
  - $D_L = A_L - A_{L - 1}$ увеличивается на $X$ (изменилось $A_L$, а $A_{L - 1}$ --- нет). 
  - $D_{R + 1} = A_{R + 1} - A_R$ уменьшается на $X$ (изменилось $A_R$, а $A_{R + 1}$ --- нет).
     
- Не забудьте проверить, что $R + 1 \le N$, чтобы избежать выхода за границы массива.
  - Часто проще выделить $D$ размером $N + 1$, чтобы избежать лишней проверки.
  
- После выполнения всех операций мы можем восстановить результирующий массив $A$, вычислив префиксные суммы массива $D$.
  - Обратите внимание, что этот подход возможен только потому, что нам не нужны промежуточные состояния $A$.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> diff(n + 1, 0); // Разностный массив размером n + 1

    // Применяем все операции к разностному массиву (индексация с 0)
    for (const auto& [left, right, delta] : queries) {
        diff[left] += delta;
        diff[right + 1] -= delta;
    }

    // Восстанавливаем результирующий массив A, вычисляя префиксные суммы D
    std::vector<int> ans(diff.begin(), diff.end());
    for (int i = 1; i < n; ++i) {
        ans[i] += ans[i - 1];
    }

    return ans;
}
```

### Максимизация суммы запросов суммы в диапазоне

#### Задача

У вас есть массив $A$ размером $N$ и $Q$ запросов. 

Каждый запрос содержит два целых числа $L$ и $R$ --- вам нужно найти сумму элементов в диапазоне $[L, R]$.

Переставьте элементы массива $A$, чтобы максимизировать общую сумму ответов на все запросы.

#### Решение

- Обозначим общую сумму ответов на все запросы как $S$.
  - $S = \sum_{j = 1}^{Q} \sum_{i = L_j}^{R_j} A_i$.

- Обозначим предикат, что позиция $i$ включена в запрос $j$, как $I_{i, j}$:
  - $I_{i, j} = 1$, если $L_j \le i \le R_j$;
  - $I_{i, j} = 0$, в противном случае.

- Тогда мы можем переписать $S$ как:
  - $S = \sum_{j = 1}^{Q} \sum_{i = 1}^{N} A_i \cdot I_{i, j}$.
  - Это можно переписать как $S = \sum_{i = 1}^{N} A_i \cdot \left( \sum_{j = 1}^{Q} I_{i, j} \right)$.

- Легко увидеть, что $\left( \sum_{j = 1}^{Q} I_{i, j} \right)$ --- это количество запросов, которые включают позицию $i$.
  - Обозначим это значение через **частоту** $F_i$ позиции $i$.
  - Таким образом, $S = \sum_{i = 1}^{N} A_i \cdot F_i$.
  
- $F_i$ можно вычислить с помощью подхода массива разностей:
  - Каждый запрос $[L, R]$ увеличивает частоту всех позиций в диапазоне $[L, R]$ на $1$.

- Чтобы максимизировать $S$, нам нужно объединить наибольшие элементы массива $A$ с наибольшими частотами в $F$.
  - Это можно сделать, отсортировав оба массива $A$ и $F$ в неубывающем порядке и вычислив сумму произведений.
    - $S = \sum_{i = 1}^{N} A^S_i \cdot F^S_i$, где $A^S$ и $F^S$ --- отсортированные массивы.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> freq(n + 1, 0); // Массив частот

    // Вычисляем частоты с помощью подхода разностного массива
    for (const auto& [left, right] : queries) {
        freq[left] += 1;
        freq[right + 1] -= 1;
    }

    // Восстанавливаем частоты, вычисляя префиксные суммы
    for (int i = 1; i < n; ++i) {
        freq[i] += freq[i - 1];
    }
    
    freq.pop_back(); // Удаляем лишний элемент

    std::sort(a.begin(), a.end());
    std::sort(freq.begin(), freq.end());

    ans_t ans  = 0;
    for (int i = 0; i < n; ++i) {
        ans += (ans_t)a[i] * freq[i];
    }

    return ans;
}
```
