# Онлайн-запросы на критических точках

До этого мы обсуждали задачи, в которых все запросы были известны заранее.

Но что делать, если запросы заранее неизвестны?

Либо запросы типа "get" перемешаны с запросами типа "update"?

В подобных случаях нам может помочь техника **сжатия координат**.

## Сжатие координат

Мы разделим процесс обработки интервалов стабильности на две части:

- нахождение и **нумерация** критических точек в порядке возрастания - это и есть **сжатие координат**;
- затем мы используем эти сжатые координаты для ответов на имеющиеся запросы.

Основное удобство данного подхода заключается в возможности использования различных структур данных, реализующих те или иные **запросы над диапазонами** массива:

- разностный массив;
- дерево отрезков / Фенвика;
- корневая декомпозиция;
- и т.д.

### Массив критических точек

Для начала нам нужно собрать все критические точки в сортированном порядке.

Чаще всего стремятся оставить только уникальные значения, чтобы минимизировать размер результирующего массива.

#### Дерево поиска

```cpp
auto get_critical_points = [&]() {
    search_tree_set<int> critical_points_set;
    
    // Собираем критические точки из отрезков
    for (const auto& [left, right, _] : segments) {
        critical_points_set.insert(left);
        critical_points_set.insert(right + 1);
    }
    
    // Собираем критические точки из запросов
    for (const auto& [coord, _] : queries) {
        critical_points_set.insert(coord);
    }
    
    // Переносим в вектор
    std::vector<int> critical_points(critical_points_set.begin(), critical_points_set.end());
    
    return critical_points;
}
```

#### Сортировка и удаление дубликатов

```cpp
auto get_critical_points = [&]() {
    std::vector<int> critical_points;

    // Собираем критические точки из отрезков 
    for (const auto& [left, right, _] : segments) {
        critical_points.push_back(left);
        critical_points.push_back(right + 1);
    }

    // Собираем критические точки из запросов

    for (const auto& [coord, _] : queries) {
        critical_points.push_back(coord);
    }

    // Сортируем и удаляем дубликаты
    std::sort(critical_points.begin(), critical_points.end());
    
    // магия C++
    
    // удаляет все элементы в заданном промежутке
    critical_points.erase(
        // переносит все уникальные элементы в начало, возвращает "новый конец"
        // ожидает отсортированный промежуток 
        std::unique(critical_points.begin(), critical_points.end()),  
        critical_points.end()
    );
    
    /*
    В случае, если вы используете язык без встроенной поддержки удаления дубликатов,
    вы можете сделать это вручную:

    std::vector<int> unique_points;
    for (size_t i = 0; i < critical_points.size(); ++i) {
        if (i == 0 || critical_points[i] != critical_points[i - 1]) {
            unique_points.push_back(critical_points[i]);
        }
    }
    
    */    
    
    return critical_points;
}
```

### Сопоставление сжатых координат

Осталось научиться сопоставлять исходные координаты с их сжатыми аналогами.

#### Хеш-таблица

Данный подход актуален только, если координаты запросов так же известны заранее, чтобы их можно было сжать.

```cpp
auto build_compression_map = [&](const std::vector<int>& critical_points) {
    hash_table_map<int, int> compression_map;
    
    for (size_t i = 0; i < critical_points.size(); ++i) {
        compression_map[critical_points[i]] = i;
    }
    
    return compression_map;
}

auto compress_coordinate = [&](int coord, const hash_table_map<int, int>& compression_map) {
    return compression_map.get(coord); // возвращаем сжатую координату
}
```

#### Двоичный поиск

Хотя данный приём имеет теоретически худшую асимптотику $O(\log N)$ на запрос, на практике он часто оказывается быстрее за счёт меньших констант и отсутствия накладных расходов на хеш-таблицы.

Также данный подход работает даже в случае, если заранее известны только координаты отрезков, но не запросов.

```cpp
auto compress_coordinate = [&](int coord, const std::vector<int>& critical_points) {
    // Ищем двоичным поиском позицию coord в массиве critical_points
    auto it = std::lower_bound(critical_points.begin(), critical_points.end(), coord);
    
    // Возвращаем индекс сжатой координаты
    return std::distance(critical_points.begin(), it);
}
```

## Применение в задачах

### Количество покрывающих отрезков

#### Задача

Даны $N$ отрезков $[L_i, R_i]$ на числовой прямой и $Q$ запросов $x_j$.

Для $j$-го запроса найдите количество отрезков, которые покрывают точку $x_j$.

Запросы необходимо обработать в режиме онлайн.

#### Решение

- Сожмём координаты границ отрезков.
- Применим разностный массив для операций "инкремент диапазона".
- Для ответа на каждый запрос найдём интервал, в который входит точка.
  - Поиск интервала выполняется с помощью двоичного поиска.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> critical_points = get_critical_points();
    
    // Строим разностный массив
    std::vector<int> cover_count(critical_points.size() + 1, 0);
    for (const auto& [left, right] : segments) {
        int compressed_left = compress_coordinate(left, critical_points);
        int compressed_right = compress_coordinate(right, critical_points);
        
        cover_count[compressed_left] += 1;
        cover_count[compressed_right + 1] -= 1;
    }
    
    // Вычисляем количество покрытий
    for (size_t i = 1; i < cover_count.size(); ++i) {
        cover_count[i] += cover_count[i - 1];
    }
    
    // Отвечаем на запросы
    std::vector<int> answers;
    for (const auto& coord : queries) {
        int compressed_coord = compress_coordinate(coord, critical_points);
        answers.push_back(cover_count[compressed_coord]);
    }
    
    return answers;
}
```

### Сумма цветов точек в диапазоне

#### Задача

Даны $N$ отрезков $[L_i, R_i]$ на числовой прямой, каждый из которых имеет цвет $C_i$.

Цвет точки $x$ равен сумме цветов покрывающих её отрезков: $color(x) = \sum_{i: L_i \le x \le R_i} C_i$.

Также даны $Q$ запросов $[S_j, E_j]$ - найти сумму цветов точек в диапазоне: $\sum_{x = S_j}^{E_j} color(x)$.

Запросы необходимо обработать в режиме онлайн.

#### Решение

- Сожмём координаты границ отрезков.
- Применим разностный массив для операций "инкремент диапазона" с учётом цвета отрезков.
- Для ответа на каждый запрос найдём сжатые координаты границ диапазона и вычислим сумму с помощью префиксных сумм.
- Каждый запрос разбивается на две части:
  - сумма от начала до $E_j$;
  - сумма от начала до $S_j - 1$;
  - разность двух сумм даёт ответ на запрос.
- Учтите, что координаты запроса $x$ ($S_j - 1$ и $E_j$) могут находиться в середине интервалов стабильности.
  - находим ближайшую меньшую критическую точку $K_i$ для точки-запроса.
  - для неё извлекаем заранее посчитанную префиксную сумму.
  - для отрезка $(K_i, x]$ цвет точек постоянен, поэтому сумма равна $color(K_i) \cdot (x - K_i)$.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> critical_points = get_critical_points();
    
    // Строим разностный массив с учётом цвета
    std::vector<ans_t> color_sum(critical_points.size() + 1, 0);
    for (const auto& [left, right, color] : segments) {
        int compressed_left = compress_coordinate(left, critical_points);
        int compressed_right = compress_coordinate(right, critical_points);
        
        color_sum[compressed_left] += color;
        color_sum[compressed_right + 1] -= color;
    }
    
    // Вычисляем цвет точек
    for (size_t i = 1; i < color_sum.size(); ++i) {
        color_sum[i] += color_sum[i - 1];
    }
    
    // Вычисляем префиксные суммы цветов
    std::vector<ans_t> prefix_sum(color_sum.size(), 0);
    for (size_t i = 0; i + 1 < color_sum.size(); ++i) {
        ans_t segment_length = critical_points[i + 1] - critical_points[i];
        prefix_sum[i + 1] = prefix_sum[i] + color_sum[i] * segment_length;
    }
    
    auto calculate_prefix_sum = [&](int coord) {
        int compressed_coord = compress_coordinate(coord, critical_points);
        ans_t result = prefix_sum[compressed_coord];
        
        // Учёт части от критической точки до coord
        if (critical_points[compressed_coord] < coord) {
            result += color_sum[compressed_coord] * (coord - critical_points[compressed_coord]);
        }
        
        return result;
    };
    
    // Отвечаем на запросы
    std::vector<ans_t> answers;
    for (const auto& [start, end] : queries) {
        int compressed_start = compress_coordinate(start, critical_points);
        int compressed_end = compress_coordinate(end, critical_points);
        
        ans_t answer = calculate_prefix_sum(end) - calculate_prefix_sum(start - 1);
        
        answers.push_back(answer);
    }
    
    return answers;
}
```

### Произведение цветов точек в диапазоне

#### Задача

Даны $N$ отрезков $[L_i, R_i]$ на числовой прямой, каждый из которых имеет цвет $C_i$.

Цвет точки $x$ равен сумме цветов покрывающих её отрезков: $color(x) = \sum_{i: L_i \le x \le R_i} C_i$.

Также даны $Q$ запросов $[S_j, E_j]$ - найти **произведение** цветов точек в диапазоне: $\sum_{x = S_j}^{E_j} color(x)$.

Запросы необходимо обработать в режиме онлайн.

Выводить ответы на запросы надо по заданному модулю $M$.

#### Решение

- Сожмём координаты границ отрезков.
- Применим разностный массив для операций "инкремент диапазона" с учётом цвета отрезков.
- Произведение на каждом интервале можно посчитать через быстрое возведение в степень.
- Так как $M$ может быть любым, то деление по модулю не гарантировано.
  - Соответственно, подход с префиксными произведениями применять нельзя.
- Разобьём запрос на **три** части:
  - Пусть $S_j < K_S < K_E < E_j$, где $K_S$ и $K_E$ --- ближайшие критические точки к $S_j$ и $E_j$ соответственно.
  - Вычислим произведение на трёх отрезках:
    - от $S_j$ до $K_S$ - $color(S_j)$ в степени ${(K_S - S_j + 1)}$;
    - от $K_S$ до $K_E$ - произведение интервалов в диапазоне.
    - от $K_E$ до $E_j$ - $color(E_j)$ в степени ${(E_j - K_E)}$.
- Произведение интервалов можно вычислять с помощью различных структур данных, например:
  - дерево отрезков;
  - корневая декомпозиция.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> critical_points = get_critical_points();
    
    // Строим разностный массив с учётом цвета
    std::vector<ans_t> color_sum(critical_points.size() + 1, 0);
    for (const auto& [left, right, color] : segments) {
        int compressed_left = compress_coordinate(left, critical_points);
        int compressed_right = compress_coordinate(right, critical_points);
        
        color_sum[compressed_left] += color;
        color_sum[compressed_right + 1] -= color;
    }
    
    // Вычисляем цвет точек
    for (size_t i = 1; i < color_sum.size(); ++i) {
        color_sum[i] += color_sum[i - 1];
    }
    
    // Вычисляем произведения на каждом интервале
    std::vector<ans_t> products(critical_points.size(), 1);
    for (size_t i = 0; i + 1 < color_sum.size(); ++i) {
        ans_t segment_length = critical_points[i + 1] - critical_points[i];
        products[i] = fast_pow(color_sum[i], segment_length, M);
    }
    
    // Строим структуру данных для вычисления произведений в диапазоне
    RangeProduct<ans_t> range_product_ds(products);
    
    // Отвечаем на запросы
    std::vector<ans_t> answers;
    for (const auto& [start, end] : queries) {
        int compressed_start = compress_coordinate(start, critical_points) + 1; // ближайшая большая
        int compressed_end = compress_coordinate(end, critical_points);
        
        ans_t answer = 1;
        // Левая часть от start до ближайшей критической точки
        if (critical_points[compressed_start] > start) {
            ans_t left_color = color_sum[compressed_start];
            ans_t left_length = critical_points[compressed_start] - start;
            answer = (answer * fast_pow(left_color, left_length, M)) % M;
        }
        
        // Средняя часть от ближайшей критической точки до ближайшей критической точки
        if (compressed_start < compressed_end) {
            ans_t middle_product = range_product_ds.query(compressed_start, compressed_end - 1);
            answer = (answer * middle_product) % M;
        }
        
        // Правая часть от ближайшей критической точки до end
        if (critical_points[compressed_end] <= end) {
            ans_t right_color = color_sum[compressed_end];
            ans_t right_length = end - critical_points[compressed_end] + 1;
            answer = (answer * fast_pow(right_color, right_length, M)) % M;
        }
        
        answers.push_back(answer);
    }
    
    return answers;
}
```
