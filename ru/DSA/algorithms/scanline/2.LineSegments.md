# Отрезки на прямой

В предыдущем разделе мы обсудили некоторые задачи с применением операций "инкремент диапазона" к массивам.

Наиболее известные применения этой техники связаны с отрезками на прямой.

Мы будем исходить из предположения, что:

- отрезки расположены на целочисленной прямой $[0, M)$;
- допускается сложность по времени / памяти $O(M)$.

## Задачи

### Длина объединения отрезков

#### Задача

Даны $N$ отрезков $[L_i, R_i]$ на прямой.

Найдите общую длину их объединения за $O(N + M)$ времени.

#### Решение

- Обозначим массив $C$ размером $M$, инициализированный нулями.
  - $C_i$ будет хранить, сколько отрезков покрывают точку $i$ на прямой.
  - Тогда общая длина объединения отрезков --- это количество позиций $i$, где $C_i > 0$.
  
- Каждый отрезок $[L_i, R_i]$ по сути является операцией инкремента диапазона на массиве $C$.
  - Используйте уже известную технику "разностного массива", чтобы применить все инкременты за $O(N)$ времени.
  - Затем восстановите массив $C$, вычислив префиксные суммы за $O(M)$ времени.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> covered(m + 1, 0); // Разностный массив размером m + 1
    // Примените все отрезки как операции инкремента диапазона к разностному массиву (1-индексация)
    for (const auto& [left, right] : segments) {
        covered[left] += 1;
        covered[right + 1] -= 1;
    }
    
    // Восстановите массив C, вычислив префиксные суммы разностного массива
    for (int i = 1; i <= m; ++i) {
        covered[i] += covered[i - 1];
    }
    
    // Подсчитайте количество позиций, покрытых хотя бы одним отрезком
    ans_t ans = 0;
    for (int i = 1; i <= m; ++i) {
        if (covered[i] > 0) {
            ans += 1;
        }
    }
    
    return ans;
}
```

### Количество пересечений

#### Задача

Даны $N$ отрезков $[L_i, R_i]$ на прямой.

Для каждого отрезка подсчитайте, сколько других отрезков пересекаются с ним.

#### Решение

- Обозначим $C_i$ как количество отрезков, **пересекающихся** с $i$-м отрезком.
  - Два отрезка $[L_i, R_i]$ и $[L_j, R_j]$ пересекаются тогда и только тогда, когда $\max(L_i, L_j) \le \min(R_i, R_j)$.
  - Это неравенство немного сложно использовать напрямую, поэтому давайте немного преобразуем задачу.
- Обозначим $S_i$ как количество отрезков, **не пересекающихся** с $i$-м отрезком.
  - Тогда $C_i = N - 1 - S_i$.
  - Два отрезка $[L_i, R_i]$ и $[L_j, R_j]$ не пересекаются в двух **независимых** случаях:
    - $R_i < L_j$,
    - $R_j < L_i$.
- Таким образом, $S_i$ можно вычислить как сумму двух независимых подсчетов:
  - количество отрезков $j$, где $R_j < L_i$, обозначим это как $S^L_i$,
  - количество отрезков $j$, где $R_i < L_j$, обозначим это как $S^R_i$.
- Давайте вычислим $S^L_i$ для всех отрезков:
  - $S^L_i = \sum_{k = 0}^{L_i - 1} E_k$, где $E_k$ --- количество отрезков, заканчивающихся в позиции $k$.
    - $S^L_i$ по сути является **запросом префиксной суммы** на массиве $E$ в позиции $L_i - 1$.
- Сегмент $i$ заканчивается в позиции $R_i$, поэтому мы можем построить массив $E$ как `e[R_i] += 1` для каждого отрезка $i$.
- Аналогично, мы можем вычислить $S^R_i$ для всех отрезков, но используя **суффиксные суммы**.
  - В качестве альтернативы, мы можем развернуть прямую и отрезки и использовать тот же подход, что и для $S^L_i$.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> starts(m + 1, 0); // starts[i]
    std::vector<int> ends(m + 1, 0); // ends[i]

    // Построим массивы starts и ends
    for (const auto& [left, right] : segments) {
        starts[left] += 1;
        ends[right] += 1;
    }

    // Вычислим префиксные и суффиксные суммы
    std::vector<int> s_right(starts.begin(), starts.end());
    std::vector<int> s_left(ends.begin(), ends.end());
    
    for (int i = 1; i <= m; ++i) {
        s_left[i] += s_left[i - 1];
    }
    
    for (int i = m - 1; i >= 0; --i) {
        s_right[i] += s_right[i + 1];
    }

    std::vector<int> ans(n, 0);
    for (int i = 0; i < n; ++i) {
        const auto& [left, right] = segments[i];
        int to_the_left = (left > 0) ? s_left[left - 1] : 0;
        int to_the_right = (right < m) ? s_right[right + 1] : 0;
        int not_intersecting = to_the_left + to_the_right;
        ans[i] = (n - 1) - not_intersecting;
    }

    return ans;
}
```

### Максимальное количество непересекающихся отрезков

#### Задача

Даны $N$ отрезков $[L_i, R_i]$ на прямой.

Найдите максимальное количество непересекающихся отрезков и выведите любой такой набор отрезков.

#### Решение

- Вы можете подумать, что это еще одна задача на подход "инкремент диапазона".
  - Возможно, вы сможете найти какое-то решение, используя эту технику, но есть гораздо более простое.
- Вместо этого используйте **жадный подход**:
  - Отсортируйте отрезки по их **правому концу** в порядке возрастания. 
    - Вы можете отсортировать отрезки с помощью сортировки подсчетом за $O(M)$.
  - Перебирайте отрезки в этом порядке и поддерживайте правый конец последнего добавленного отрезка.
    - Добавьте в ответ первый отрезок, который начинается после этого конца, и обновите конец.

#### Реализация

```cpp
auto get_ans = [&]() {
    // Отсортируйте отрезки по их правому концу
    using endpoint_t = std::pair<int, int>; // (правый_конец, индекс)
    
    std::vector<endpoint_t> endpoints(n);
    for (int i = 0; i < n; ++i) {
        const auto& [left, right] = segments[i];
        endpoints[i] = {right, i};
    }
    
    std::sort(endpoints.begin(), endpoints.end());
    
    std::vector<int> ans_indices;
    int last_endpoint_right = neg_inf;
    for (const auto& [endpoint_right, endpoint_index] : endpoints) {
        const auto& [left, right] = segments[endpoint_index];
        if (left > last_endpoint_right) {
            ans_indices.push_back(endpoint_index);
            last_endpoint_right = endpoint_right;
        }
    }
    
    return ans_indices;
}
```
