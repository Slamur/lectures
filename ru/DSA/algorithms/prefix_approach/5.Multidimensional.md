# Многомерный префиксный подход

При работе с многомерными массивами префиксный подход можно расширить для обработки подматриц.

Для простоты рассмотрим 2D массив размером $R \times C$.

**2D Префикс** $(i, j)$ 2D массива --- это подматрица, которая содержит все элементы $A_{x, y}$ такие, что $x \in (0, i]$ и $y \in (0, j]$.

## Вычисление 2D префиксов

Предположим, у нас есть бинарная операция $\oplus$ с единичным элементом $e$.

Существуют два основных подхода для вычисления 2D префиксов в зависимости от того, является ли операция обратимой или нет.

### Общий подход

Этот подход работает для любой бинарной операции.

- Используйте временный 2D массив $RP$ размером $(R + 1) \times (C + 1)$, где для фиксированного $i$:
  - $RP_{i, 0} = e$ для всех $i$;
  - $RP_{i, j} = RP_{i, j - 1} \oplus A_{i, j}$ для всех $j$ от $1$ до $C$.
- Затем вычислите окончательный 2D префиксный массив $Pref$ размером $(R + 1) \times (C + 1)$:
  - $Pref_{0, j} = e$ для всех $j$;
  - $Pref_{i, j} = Pref_{i - 1, j} \oplus RP_{i, j}$ для всех $i$ от $1$ до $R$.
- Можно использовать аналогичный подход, сначала вычисляя префиксы по столбцам, а затем по строкам.

#### Реализация

```cpp
auto get_2d_prefix_min = [&](const std::vector<std::vector<int>>& a) {
    size_t rows_cnt = a.size();
    size_t cols_cnt = a[0].size();
    
    int identity = INT_MAX; // Нейтральный элемент для операции минимума

    std::vector<std::vector<int>> row_prefs(rows_cnt + 1, std::vector<int>(cols_cnt + 1, identity));
    for (size_t i = 0; i < rows_cnt; i++) {
        for (size_t j = 0; j < cols_cnt; j++)
            row_prefs[i + 1][j + 1] = std::min(row_prefs[i + 1][j], a[i][j]);
        }
    }   
    
    std::vector<std::vector<int>> prefs(rows_cnt + 1, std::vector<int>(cols_cnt + 1, identity));
    for (size_t j = 0; j < cols_cnt; j++) {
        for (size_t i = 0; i < rows_cnt; i++)
            prefs[i + 1][j + 1] = std::min(prefs[i][j + 1], row_prefs[i + 1][j + 1]);
        }
    }
}
```

### Подход с обратимой операцией

Если бинарная операция обратима, то можно вычислить 2D префиксы более простым способом:

$Pref_{i, j} = (Pref_{i - 1, j} \oplus Pref_{i, j - 1} \ominus Pref_{i - 1, j - 1}) \oplus A_{i, j}$:

- Элементы в $i$-й строке слева от $j$-й добавляются только один раз;
- Элементы в $j$-й колонне выше $i$-й добавляются только один раз;
- Элементы в верхнем левом подмассиве $(i - 1, j - 1)$ добавляются дважды, поэтому нам нужно вычесть их один раз.

#### Реализация

```cpp
auto get_2d_prefix_sum = [&](const std::vector<std::vector<int>>& a) {
    size_t rows_cnt = a.size();
    size_t cols_cnt = a[0].size();

    int identity = 0; // Нейтральный элемент для операции суммы

    std::vector<std::vector<int>> prefs(rows_cnt + 1, std::vector<int>(cols_cnt + 1, identity));
    for (size_t i = 0; i < rows_cnt; i++) {
        for (size_t j = 0; j < cols_cnt; j++) {
            prefs[i + 1][j + 1] = prefs[i][j + 1] + prefs[i + 1][j] - prefs[i][j] + a[i][j];
        }
    } 
}
```

## Запросы на подмассивах (для обратимых операций)

Если бинарная операция обратима, то можно отвечать на запросы подматрицы, используя только 2D префиксные результаты.

Пусть $F(R_1, C_1, R_2, C_2)$ будет результатом применения бинарной операции ко всем элементам в подматрице, определенной верхним левым углом $(R_1, C_1)$ и нижним правым углом $(R_2, C_2)$.

Тогда мы можем выразить:

$F(R_1, C_1, R_2, C_2) = Pref_{R_2, C_2} \ominus Pref_{R_1 - 1, C_2} \ominus Pref_{R_2, C_1 - 1} \oplus Pref_{R_1 - 1, C_1 - 1}$:

- Элементы в префиксе $(R_2, C_2)$ добавляются один раз;
- Элементы в префиксе $(R_1 - 1, C_2)$ (над подматрицей) вычитаются один раз;
- Элементы в префиксе $(R_2, C_1 - 1)$ (слева от подматрицы) вычитаются один раз;
- Элементы в префиксе $(R_1 - 1, C_1 - 1)$ (верхний левый угол) вычитаются дважды, поэтому нам нужно добавить их один раз.

#### Реализация

```cpp
auto get_submatrix_sum = [&](const std::vector<std::vector<int>>& pref_sums,
                             size_t r1, size_t c1, size_t r2, size_t c2) {
    return pref_sums[r2][c2]
           - pref_sums[r1 - 1][c2]
           - pref_sums[r2][c1 - 1]
           + pref_sums[r1 - 1][c1 - 1];
}
```

### Максимальная сумма подматрицы

#### Задача

У вас есть 2D массив размером $R \times C$.

Вам нужно найти подматрицу с максимальной суммой элементов.

#### Решение

- Вычислите 2D префиксные суммы.
- В 1D случае мы фиксировали правую границу $R$ и искали лучшую левую границу $L$.
  - этот подход нельзя расширить как есть на 2D случай, потому что у нас есть две границы для фиксации --- правую и нижнюю.
- Вместо этого мы можем зафиксировать верхние и нижние границы $R_1$ и $R_2$ и свести задачу к 1D случаю.
  - Для фиксированного $C_2$ вам нужно найти лучший $C_1$, чтобы максимизировать сумму подматрицы $(R_1, C_1)$ до $(R_2, C_2)$.
- Общая временная сложность составляет $O(R^2 \cdot C)$.
  - Если $C > R$, то лучше зафиксировать левые и правые границы и перебирать верхние и нижние границы --- общая временная сложность составит $O(C^2 \cdot R)$.

#### Реализация

```cpp
auto get_max_submatrix_sum = [&](const std::vector<std::vector<int>>& a) {
    size_t rows_cnt = a.size();
    size_t cols_cnt = a[0].size();

    // Вычисляем 2D префиксные суммы
    std::vector<std::vector<int>> pref_sums = calculate_2d_prefix_sums(a);

    int max_sum = INT_MIN;
    for (size_t top = 1; top <= rows_cnt; top++) {
        for (size_t bottom = top; bottom <= rows_cnt; bottom++) {
            int min_prefix_sum = 0;
            
            for (size_t col = 1; col <= cols_cnt; col++) {
                // Вычисляем префиксную сумму от верхней до нижней границы
                int right_sum = get_submatrix_sum(pref_sums, top, 1, bottom, col);
                max_sum = std::max(max_sum, right_sum - min_prefix_sum);
                min_prefix_sum = std::min(min_prefix_sum, right_sum);
            }
        }
    }
    
    return max_sum;
}
```

## Обобщение на более высокие размерности

### Вычисление

Обычно общий подход проще реализовать для более высоких размеров --- просто перебирайте все размеры один за другим, вычисляя префиксы вдоль каждого размера.

Подход с обратимой операцией также можно обобщить, но формула становится гораздо более сложной с каждым новым размером.

### Запросы на подмассивах (для обратимых операций)

Формулу также можно обобщить на более высокие размерности, используя **принцип включения-исключения**:

- это требует $2^D$ слагаемых для $D$-мерного массива;
- каждое слагаемое соответствует одному углу гиперпрямоугольника, определяемого запросом;
- знак каждого слагаемого определяется четностью количества размерностей, в которых угол находится на "нижней" стороне диапазона запроса.

#### Реализация

`bit_count` --- это абстрактная функция, которая считает количество `1` битов в двоичном представлении числа.

```cpp
auto get_subhyperrectangle_sum = [&](const std::vector<std::vector<std::vector<int>>>& pref_sums,
                                     const std::vector<size_t>& start,
                                     const std::vector<size_t>& end) {
    int result = 0;
    
    size_t dimensions = start.size();
    size_t corners_cnt = 1 << dimensions; // 2^D углов
    
    for (size_t corner = 0; corner < corners_cnt; corner++) {
        int sign = (bit_count(corner) % 2 == 0) ? 1 : -1;
        
        std::vector<size_t> indices(dimensions);
        for (size_t dim = 0; dim < dimensions; dim++) {
            if (corner & (1 << dim))
                indices[dim] = end[dim];
            else
                indices[dim] = start[dim] - 1;
        }
        
        result += sign * get_pref_value(pref_sums, indices);
    }
    
    return result;
}
```
