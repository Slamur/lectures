# Языки

Практически все современные языки программирования имеют встроенные функции или функции стандартной библиотеки, реализующие префиксный подход для накопления заданных бинарных операций по диапазонам элементов.

Обычно они делятся на две категории:

- Функции, которые накапливают по диапазону и возвращают окончательный результат.
- Функции, которые накапливают по диапазону и сохраняют все промежуточные результаты.

## C++

Обе функции находятся в заголовочном файле `<numeric>` стандартной библиотеки C++.

- [`std::accumulate`](https://en.cppreference.com/w/cpp/algorithm/accumulate) --- накапливает по диапазону и возвращает окончательный результат.
  - параметры:
    - "входные" итераторы --- диапазон для накопления;
    - начальное значение для накопления;
    - (необязательно) бинарная операция для накопления (по умолчанию `+`).
  
- [`std::partial_sum`](https://en.cppreference.com/w/cpp/algorithm/partial_sum) --- накапливает по диапазону и сохраняет все промежуточные результаты.
  - параметры:
    - "входные" итераторы --- диапазон для накопления;
    - "выходной" итератор --- куда будут сохранены результаты.
    - (необязательно) бинарная операция для накопления (по умолчанию `+`).

## Java

- [`Stream.reduce`](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/stream/Stream.html#reduce(T,java.util.function.BinaryOperator)) (метод экземпляра) --- накапливает по потоку и возвращает окончательный результат.
  - параметры:
    - единичное значение для накопления;
    - бинарный оператор для накопления.
    
- [`Arrays.parallelPrefix`](https://docs.oracle.com/en/java/javase/21/docs/api/java.base/java/util/Arrays.html#parallelPrefix(java.lang.Object[],int,int,java.util.function.BinaryOperator)) (статический метод) --- накапливает по массиву и сохраняет все промежуточные результаты.
  - параметры:
    - массив для накопления;
    - (необязательно) от индекса (включительно);
    - (необязательно) до индекса (исключительно);
    - бинарный оператор для накопления.

## Python

- [`functools.reduce`](https://docs.python.org/3/library/functools.html#functools.reduce) --- накапливает по итерируемому объекту и возвращает окончательный результат.
  - параметры:
    - бинарная функция для накопления;
    - итерируемый объект для накопления;
    - (необязательно) начальное значение для накопления.

- [`itertools.accumulate`](https://docs.python.org/3/library/itertools.html#itertools.accumulate) --- накапливает по итерируемому объекту и возвращает итератор промежуточных результатов.
  - параметры:
    - итерируемый объект для накопления;
    - (необязательно) бинарная функция для накопления (по умолчанию `+`).
