# Языки

## C++

В стандартной библиотеке C++ есть функции (в заголовке `<numeric>`), которые накапливают специфические бинарные операции по диапазонам элементов:

- `std::accumulate` --- накапливает по диапазону и возвращает окончательный результат.
  - параметры:
    - "входные" итераторы --- диапазон для накопления;
    - начальное значение для накопления;
    - (необязательно) бинарная операция для накопления (по умолчанию `+`).
- `std::partial_sum` --- накапливает по диапазону и сохраняет все промежуточные результаты.
  - параметры:
    - "входные" итераторы --- диапазон для накопления;
    - "выходной" итератор --- куда будут сохранены результаты.
    - (необязательно) бинарная операция для накопления (по умолчанию `+`).

## Java

В стандартной библиотеке Java есть функции, накапливающие специфические бинарные операции по диапазонам элементов:

- `Stream.reduce` --- накапливает по потоку и возвращает окончательный результат.
  - параметры:
    - единичное значение для накопления;
    - бинарный оператор для накопления.
- `Arrays.parallelPrefix` --- накапливает по массиву и сохраняет все промежуточные результаты.
  - параметры:
    - массив для накопления;
    - (необязательно) от индекса (включительно);
    - (необязательно) до индекса (исключительно);
    - бинарный оператор для накопления.

## Python

В стандартной библиотеке Python есть функция (в модуле `itertools`), накапливающая специфические бинарные операции по диапазонам элементов:

- `itertools.accumulate` --- накапливает по итерируемому объекту и возвращает итератор промежуточных результатов.
  - параметры:
    - итерируемый объект для накопления;
    - (необязательно) бинарная функция для накопления (по умолчанию `+`).
