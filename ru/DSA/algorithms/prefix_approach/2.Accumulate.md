# Операция накопления

Во многих задачах более эффективно обрабатывать префиксы / суффиксы от пустых до всего массива:

- $Pref_i = Pref_{i - 1} \oplus A_i$, где $\oplus$ - операция объединения предыдущего результата и нового элемента.
- $Suff_i = A_i \oplus Suff_{i + 1}$.

Для пустых префиксов / суффиксов результат обычно известен (нейтральный элемент операции $\oplus$).

В некоторых случаях возможно заменить массив накопленных результатов одной переменной, которая хранит текущий результат.

## Требования к операции накопления

В общем случае операция накопления должна быть **ассоциативной**, то есть для любых $a$, $b$, $c$ должно выполняться:

$ (a \oplus b) \oplus c = a \oplus (b \oplus c) $.

Также для операции желательно существование **нейтрального элемента** $e$, такого что для любого $a$:

$ a \oplus e = e \oplus a = a $.

Фактически в таком случае мы определяем **моноид** - операцию над множеством $M$ с ассоциативной бинарной операцией $\oplus$ и нейтральным элементом $e \in M$.

## Операции с фиксированным размером результата

Самые базовые примеры накопительных операций --- это операции, результаты которых занимают $O(1)$ памяти (в скобках указаны их нейтральные элементы):

- минимум (бесконечность) / максимум (-бесконечность)
- сумма / количество (ноль)
- наибольший общий делитель (ноль) / наименьшее общее кратное (один)
- булевы функции: И (истина) / ИЛИ (ложь) / Исключающее ИЛИ (ложь)
- и т.д.

### Duff и мясо

#### Задача

Duff собирается есть мясо в течение $n$ дней.

На каждый день $i$ вам известно:

- количество мяса $a_i$, которое Duff хочет съесть;
- цена за килограмм мяса $p_i$ в этот день.

Duff может купить любое количество мяса в любой день и хранить его на будущие дни (нет ограничений на хранение).

Найдите минимальную общую сумму денег, которую Duff должна потратить, чтобы съесть необходимое количество мяса каждый день.

#### Решение

- чтобы поесть мясо в день $i$, Duff может купить его в любой день $j \le i$;
- чтобы минимизировать общие расходы, Duff всегда должна покупать мясо в день с минимальной ценой на данный момент;
- таким образом, нам нужно накапливать минимальные цены для префиксов массива $p$:
  - $mp_i = \min(mp_{i - 1}, p_i)$;
- тогда ответ будет $\sum_{i = 1}^{n} a_i \cdot mp_i$.

#### Реализация

```cpp
auto get_ans = [&]() {
  int ans = 0;
  
  int inf = 1 + *max_element(p.begin(), p.end());
  
  int min_price = inf;
  for (size_t i = 0; i < n; ++i) {
    min_price = std::min(min_price, p[i]);
    ans += a[i] * min_price;
  }
  
  return ans;
}
```

## Операции объединения с нефиксированным размером результата

Для таких операций размер $Pref_i$ обычно линейно зависит от $i$.

Таким образом, хранение всех накопленных результатов требует $O(N^2)$ памяти, что обычно неприемлемо.

Тем не менее во многих случаях возможно оптимизировать использование памяти до $O(N)$, храня результат только для последнего шага и **повторно используя** его для следующего.

Обратите внимание, что в таком случае "ответ" для префикса / суффикса не всегда совпадает с самой структурой данных, чаще всего это какая-то функция от накопленных в структуре данных. 

Общая временная сложность в этом случае составляет $O(N \cdot (Ins + Calc))$, где

- $Ins$ --- это временная сложность вставки одного элемента в структуру результата;
- $Calc$ --- это временная сложность вычисления ответа из структуры результата.

Нейтральный элемент чаще всего является пустой структурой.

### Сережа и суффиксы

#### Задача

У вас есть массив $A$ размером $n$ и $q$ запросов.

Каждый запрос содержит целое число $k$ ($1 \le k \le n$) --- вам нужно найти, сколько различных целых чисел находится в суффиксе $A_k, A_{k + 1}, \ldots, A_n$.

#### Решение

- Легко заметить, что ответ для суффикса $k \dots n$ равен размеру _множества_ значений этого суффикса.
  - давайте обозначим множество для суффикса $k \dots n$ как $S_k$.

- Операцией $\oplus$ в этом случае является операция объединения множеств $\cup$.
  - нейтральным элементом является пустое множество $\varnothing$.

- Обратите внимание, что вы можете предварительно вычислить ответы для всех суффиксов перед ответом на запросы. 
  - вычислим ответы в порядке от $n$ до $1$ --- обновляя одно и то же множество на каждой итерации.

Формально:

- $S_{n + 1} = \varnothing$;
- $S_{k} = S_{k + 1} \cup (A_k)$.

#### Реализация

```cpp
auto get_ans = [&]() {
  std::vector<size_t> suffix_uniques(n + 1, 0);

  std::unordered_set<int> suffix_set;
  for (int i = n - 1; i >= 0; --i) {
    suffix_set.insert(a[i]);
    suffix_uniques[i] = suffix_set.size();
  }
  
  std::vector<size_t> answers(q);
  for (int j = 0; j < q; ++j) {
    size_t k = queries[j] - 1;
    answers[j] = suffix_uniques[k];
  }
  
  return answers;
}
```
