# Функция накопления

Во многих задачах более эффективно обрабатывать префиксы / суффиксы от пустых до всего массива:

- $Pref_i = Combine(Pref_{i - 1}, A_i)$.
- $Suff_i = Combine(A_i, Suff_{i + 1})$.

Для пустых префиксов / суффиксов результат обычно известен (нейтральный элемент функции `Combine`).

В некоторых случаях возможно заменить массив накопленных результатов одной переменной, которая хранит текущий результат.

## Функции с фиксированным размером результата

Самые базовые примеры накопительных функций --- это функции, результаты которых занимают $O(1)$ памяти.

- минимум (бесконечность) / максимум (-бесконечность)
- сумма / количество (ноль)
- наибольший общий делитель (ноль) / наименьшее общее кратное (один)
- булевы функции: И (истина) / ИЛИ (ложь) / Исключающее ИЛИ (ложь)
- и т.д.

### Дафф и мясо

#### Задача

Дафф собирается есть мясо в течение $n$ дней.

На каждый день $i$ вам известно:

- количество мяса $a_i$, которое Дафф хочет съесть;
- цена за килограмм мяса $p_i$ в этот день.

Дафф может купить любое количество мяса в любой день и хранить его на будущие дни (нет ограничений на хранение).

Найдите минимальную общую сумму денег, которую Дафф должна потратить, чтобы съесть необходимое количество мяса каждый день.

#### Решение

- чтобы поесть мясо в день $i$, Дафф может купить его в любой день $j \le i$;
- чтобы минимизировать общие расходы, Дафф всегда должна покупать мясо в день с минимальной ценой на данный момент;
- таким образом, нам нужно накапливать минимальные цены для префиксов массива $p$:
  - $mp_i = \min(mp_{i - 1}, p_i)$;
- тогда ответ будет $\sum_{i = 1}^{n} a_i \cdot mp_i$.

#### Реализация

```cpp
auto get_ans = [&]() {
  int ans = 0;
  
  int inf = 1 + *max_element(p.begin(), p.end());
  
  int min_price = inf;
  for (size_t i = 0; i < n; ++i) {
    min_price = std::min(min_price, p[i]);
    ans += a[i] * min_price;
  }
  
  return ans;
}
```

## Функции с нефиксированным размером результата

Для таких функций размер $Pref_i$ обычно линейно зависит от $i$.

Таким образом, хранение всех накопленных результатов требует $O(N^2)$ памяти, что обычно неприемлемо.

Тем не менее, во многих случаях возможно оптимизировать использование памяти до $O(N)$, храня результат только для последнего шага и **повторно используя** его для следующего.

Общая временная сложность в этом случае составляет $O(N \cdot Ins)$, где $Ins$ --- это временная сложность вставки одного элемента в структуру результата.

Нейтральный элемент обычно является пустой структурой.

### Сережа и суффиксы

#### Задача

У вас есть массив $A$ размером $n$ и $q$ запросов.

Каждый запрос содержит целое число $k$ ($1 \le k \le n$) --- вам нужно найти, сколько различных целых чисел находится в суффиксе $A_k, A_{k + 1}, \ldots, A_n$.

#### Решение

- Легко заметить, что ответ для суффикса $k \dots n$ равен размеру _множества_ значений этого суффикса.
  - давайте обозначим множество для суффикса $k \dots n$ как $S_k$.

- Обратите внимание, что вы можете предварительно вычислить ответы для всех суффиксов перед ответом на запросы. 
  - вычислим ответы в порядке от $n$ до $1$ --- обновляя одно и то же множество на каждой итерации.

Формально:

- $S_{n + 1} = ()$ (пустое множество);
- $S_{k} = S_{k + 1} \cup (A_k)$.

#### Реализация

```cpp
auto get_ans = [&]() {
  std::vector<size_t> suffix_uniques(n + 1, 0);

  std::unordered_set<int> suffix_set;
  for (int i = n - 1; i >= 0; --i) {
    suffix_set.insert(a[i]);
    suffix_uniques[i] = suffix_set.size();
  }
  
  std::vector<size_t> answers(q);
  for (int j = 0; j < q; ++j) {
    size_t k = queries[j] - 1;
    answers[j] = suffix_uniques[k];
  }
  
  return answers;
}
```
