# Обратимые операции

Некоторые бинарные операции являются **обратимыми**:

- обозначим бинарную операцию как $\oplus$ и её инверсию как $\ominus$;
- тогда для любых элементов $a$, $b$ и $c$:
  - если $a \oplus b = c$, то $c \ominus b = a$ и $c \ominus a = b$.

Наиболее распространенные примеры обратимых операций:

- сложение / вычитание;
- умножение / деление (за исключением деления на ноль).
- XOR / XOR (XOR является своей собственной инверсией).

## Запросы на подотрезках с обратимыми операциями

Если бинарная операция обратима, то можно отвечать на запросы на подотрезках, используя только результаты префиксов.

Пусть $F(L, R) = A_{L + 1} \oplus \ldots \oplus A_R$.

Тогда мы можем выразить $F(L, R) = Pref_R \ominus Pref_L$, где $Pref_i = F(0, i)$.

### Запросы суммы на подотрезках

#### Задача

У вас есть массив из $n$ целых чисел и $q$ запросов.

Каждый запрос содержит два целых числа $L$ и $R$ ($1 \le L \le R \le n$) --- вам нужно найти сумму элементов от индекса $L$ до индекса $R$.

#### Решение

- Обратите внимание, что сумма является обратимой операцией (инверсия --- вычитание).
- Таким образом, вы можете предварительно вычислить префиксные суммы и ответить на каждый запрос как $Pref_R - Pref_L$.
- Общая временная сложность составляет $O(N + Q)$.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> prefix_sums(n + 1, 0);
    for (size_t i = 0; i < n; i++) {
        prefix_sums[i + 1] = prefix_sums[i] + a[i];
    }
        
    std::vector<int> answers;
    for (auto& [left, right] : queries) {
        int ans = prefix_sums[right] - prefix_sums[left - 1];
        answers.push_back(ans);
    }
    
    return answers;
}
```

### Подотрезок с максимальным XOR

#### Задача

У вас есть массив из $n$ целых чисел.

Вам нужно найти **максимальный** побитовый XOR ($\oplus$, `^`) подмассива $A_L, A_{L + 1}, \ldots, A_R$.

#### Решение

- $S(L, R) = Pref_R \oplus Pref_{L - 1}$.
- Зафиксируем $R$ и попробуем найти лучший $L$ для него.
  - для фиксированного $R$ значение $Pref_R$ является постоянным.
  - чтобы максимизировать $S(L, R)$, нам нужно минимизировать $Pref_{L - 1}$.
- Таким образом, мы можем перебирать $R$ от $1$ до $n$, отслеживая минимальный префиксный XOR для $L - 1$, который был замечен до сих пор.
  - Его можно хранить в массиве или даже в одной переменной.
- Общая временная сложность составляет $O(N)$.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> prefix_xors(n + 1, 0);
    for (size_t i = 0; i < n; i++) {
```

### Запросы на подотрезках с предикатом

#### Задача

У вас есть массив из $n$ целых чисел и $q$ запросов.

Также у вас есть предикатная функция $P(x)$, которая возвращает true или false для любого целого числа $x$.

Каждый запрос содержит два целых числа $L$ и $R$ ($1 \le L \le R \le n$) --- вам нужно найти, сколько элементов в подмассиве от индекса $L$ до индекса $R$ удовлетворяют предикату.

#### Решение

- Давайте создадим вспомогательный массив $B$ размером $n$, где $B_i = 1$, если $P(A_i)$ истинно, и $0$ в противном случае.
- Тогда ответ на запрос --- это сумма элементов от индекса $L$ до индекса $R$ в массиве $B$.
- Мы можем использовать идею запросов суммы на подотрезке, чтобы ответить на эти запросы.
- Общая временная сложность составляет $O(N + Q)$.

#### Реализация

```cpp
auto get_ans = [&]() {
    std::vector<int> b(n, 0);
    for (size_t i = 0; i < n; i++) {
        b[i] = P(a[i]) ? 1 : 0;
    }

    std::vector<int> prefix_sums(n + 1, 0);
    for (size_t i = 0; i < n; i++) {
        prefix_sums[i + 1] = prefix_sums[i] + b[i];
    }

    std::vector<int> answers;
    for (auto& [left, right] : queries) {
        int ans = prefix_sums[right] - prefix_sums[left - 1];
        answers.push_back(ans);
    }

    return answers;
}
```
